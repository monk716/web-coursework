# FORMA — задания 3 и 4

Учебный сайт с двумя разделами: регистрация пользователя и SPA-каталог товаров.

## Запуск

Требуется Node.js 22+ и интернет (React, PGlite, шрифты и товары загружаются из внешних источников).

```sh
npm start
```

Открыть http://127.0.0.1:3000. Установка пакетов не нужна: используются нативные ES-модули и закреплённые версии CDN.

```sh
npm test
npm run build
```

`dist/` можно опубликовать на статическом HTTPS-хостинге. Hash-маршрутизация работает без настройки перенаправлений. Для GitHub Pages достаточно загрузить `index.html`, `src/` и `.nojekyll`, затем включить Pages для основной ветки, папка `/ (root)`.

## Задание 3: регистрация

- HTML-форма: имя, email, пароль, подтверждение.
- JavaScript проверяет обязательные поля, имя (2–80), email, пароль (8–128), совпадение паролей. Ошибки показываются под полями при вводе/потере фокуса и отправке.
- Запись в PostgreSQL через PGlite 0.3.14: настоящий движок PostgreSQL, собранный в WebAssembly. Файлы БД сохраняются в IndexedDB, доступны после перезагрузки **в том же браузере на том же адресе сайта**.
- Таблица `users`: `id`, `name`, `email UNIQUE`, `password_hash`, `created_at`.
- Пароли хешируются Web Crypto PBKDF2-SHA-256, 600000 итераций, случайная 16-байтовая соль. Подтверждение пароля не сохраняется. SQL-запрос параметризован.
- Повторный email отклоняется ограничением UNIQUE, регистр email нормализуется. Web Locks предотвращает одновременное открытие одной БД в разных вкладках.

**Граница реализации:** это демонстрационная локальная регистрация. Общего серверного PostgreSQL, входа в аккаунт, почтового подтверждения и синхронизации между устройствами нет. Если преподаватель требует именно отдельный сервер MySQL/PostgreSQL, данный вариант нужно дополнить серверным API. Используйте вымышленные данные. В приватном режиме или после очистки данных сайта записи могут быть удалены браузером.

Проверка: отправить пустую форму → попробовать неправильный email/короткий пароль/разные пароли → создать пользователя → перезагрузить → повторить регистрацию с тем же email (в том числе в верхнем регистре). Ожидается ошибка дубликата.

## Задание 4: React SPA

- React 19.2.0, компоненты `App`, `Catalog`, `ProductCard`, `Registration`.
- `useState`, `useEffect`, `useMemo`, загрузка через `fetch`, отмена запросов при размонтировании.
- Открытый API DummyJSON: `/products/category/{category}?limit=100`, категории furniture, home-decoration, laptops, mobile-accessories.
- Карточки с изображениями, названием, рейтингом, ценой. Цены API указаны в USD.
- Поиск, фильтрация по категории и верхней цене, сортировка по цене и рейтингу; фильтры работают совместно.
- Состояния загрузки, ошибки API с повтором, пустые результаты, сброс фильтров.
- Дополнительно: избранное в localStorage, адаптивная верстка, доступные подписи и клавиатурная навигация.

Проверка: выбрать категорию → задать цену → отсортировать → проверить поиск и пустой результат → сбросить → добавить товар в избранное → включить фильтр избранного.
